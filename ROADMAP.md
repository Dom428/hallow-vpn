## Later

| Idea | Why it isn't in 1.0 - 1.2 |
|---|---|
| Per-app split tunnelling | Needs a network (WFP callout) driver. 1.0 splits by address, and pauses for games. |
| NordLynx without a UAC prompt per connect | WireGuard tunnels are Windows services; changing them needs admin unless a service of our own does it, and Hallow apps don't install services. WireGuard's LimitedOperatorUI only covers its own window. |
| NordLynx split tunnelling | Would need AllowedIPs per route in the elevated helper; 1.2 uses IKEv2 for "Only these" (Automatic) and says so. |
| Check latest.sig's signify signature | Needs Ed25519 (not in .NET Framework) and WireGuard's release key; 1.2 relies on HTTPS for the list plus the Authenticode check. |
| Kill switch for mobile-broadband (cellular) adapters | Windows Firewall's interface types are Wi-Fi / wired / remote access; cellular isn't tested here. |
| Kill switch IKEv2 / WireGuard only to the server in use | Every server change would change the rules = a UAC prompt each time. |

| Change the kill switch without UAC | Firewall rules are a system setting; a service could do it, but Hallow apps don't install services. |
| Nord's Threat Protection / Meshnet / dedicated IP | Need Nord's app or account API (login), which Hallow VPN deliberately never uses. |
| Pick a city | Nord's recommendations are per country; a city filter needs the full server list (several MB). |
| Turn off Windows' DNS fallback (smart multi-homed name resolution) | A Group Policy / machine setting - needs admin. 1.1 makes the VPN's DNS come first and the leak test says when a fallback exists. |
| IPv6 through the VPN | Nord's IKEv2 is IPv4 only. 1.1 warns; the kill switch blocks public IPv6. |
| A real IKEv2 probe in "Fix my connection" | Seeing whether UDP 500 / 4500 answer means starting an IKE exchange with Nord - that is connecting. 1.1 checks lookup + ping and explains error 809. |
| Hallow Torrents prefers P2P servers | Torrents isn't changed in 1.1; status.json now has `p2p` and the pipe has `connect p2p` for it. |
| Overlay / Remote cards | status.json already has what they need; Hallow Overlay and Hallow Remote can show it later. |
